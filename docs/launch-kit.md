## Hacker News

**Titre**

> Show HN: Action First – a skill that makes coding agents lead with the result

**Texte**

> Action First is a small, explicit output-style skill for coding agents. It puts the
> result or next action on the first line, numbers multi-step work, and removes filler
> without hiding required information. It is intentionally not tied to a diagnosis.
> The repository contains the canonical Agent Skill, Claude/Codex manifests, install
> instructions, and an evaluation case bank. Static checks pass; the behavioral case
> bank is published for independent testing rather than presented as already validated.

## Reddit / communauté agents

> J'ai extrait un problème simple de notre écosystème d'accessibilité : les agents
> enterrent souvent l'action sous le contexte. Action First est un mode volontaire qui
> met le résultat en premier, numérote les étapes et garde le contenu nécessaire. Le
> dépôt fournit les fichiers Claude/Codex et une banque d'évaluation. Retours recherchés
> sur l'installation et les cas où la concision retire encore trop d'information.
